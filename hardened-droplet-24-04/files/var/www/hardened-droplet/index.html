Cloudflare is working

Your Hardened Droplet is serving the web

This page came through a Cloudflare Tunnel. The Droplet has no open web ports: ports 80 and 443 are closed in its firewall.

Visitor → Cloudflare → outbound tunnel → localhost:8080

Replace this page with your app

  1. Stop the welcome page: hardened welcome off
  2. Start your app on localhost:8080.
  3. Reload this URL. It now shows your app; nothing changes in Cloudflare.
# examples
PORT=8080 npm start
python3 -m http.server 8080 --bind 127.0.0.1
docker run -p 127.0.0.1:8080:80 nginx

Using a different port?

For a quick preview run expose 3000. On your own domain, change the hostname's service to http://localhost:3000 in the Cloudflare dashboard (Zero Trust > Networks > Tunnels).
